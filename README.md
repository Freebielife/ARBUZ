## Публикация

1. Создать репозиторий `Freebielife/ARBUZ` и загрузить содержимое этого каталога
   на ветку `main`, включая `.github/workflows/update.yml`.
2. Запустить Update TON observatory в Actions и проверить успешный коммит снимка.
   Файл workflow содержит резервный cron `20,50 * * * *` (UTC). GitHub может
   задерживать cron; фактический интервал нужно подтвердить по журналу.
3. Для общего Cloudflare runner добавить ARBUZ в выбранные репозитории его
   существующего токена и затем зарегистрировать:
   `id:arbuz`, `owner:Freebielife`, `repo:ARBUZ`, `workflow:update.yml`,
   `ref:main`, `everyMinutes:30`, `phaseMinutes:20`, `enabled:true`.
   Реестр находится в Ludoman: `cloudflare/observatory-runner/src/projects.mjs`.
   Регистрация и развёртывание записи ARBUZ уже выполнены. Доступ токена и
   плановые запуски :20/:50 UTC нужно проверять по реальным журналам.
4. Загрузить корневой `index.html` в Resistance Tools для TON Site.
   Страница проверяет снимок в GitHub каждые пять минут; это отдельный интервал
   от пересборки данных. Репозиторий доступен; источники удалённого снимка
   указывают на `Freebielife/ARBUZ`.

Имя репозитория меняется автоматически по `GITHUB_REPOSITORY` при запуске Actions.
Секреты, сервер или платный API в исходники не включены.
